## 3. Створення каналу — 5 хвилин

Це єдиний етап, який я не можу зробити за вас: Telegram прив'язує канал до вашого номера телефону.

### На телефоні
1. Відкрийте Telegram → меню **☰** → **Новий канал** (або **+** → **Створити канал**).
2. **Назва:** `Рим для своїх`.
3. **Опис:** вставте текст вище.
4. Натисніть **Створити**.
5. Тип каналу: **Публічний**.
6. **Юзернейм:** `rim_dlia_svoih`.
7. Готово → **Налаштування каналу** → **Аватар** → завантажте `brand/avatar.png`.
8. **Закріплені повідомлення** → опублікуйте текст з `content/00-pinned-post.md` → закріпіть.

### На комп'ютері (швидше для тексту)
1. Telegram Desktop → **☰** → **Створити канал**.
2. Ті самі кроки. Текст зручніше вставляти з файлів.
3. Аватар: **Налаштування** → **Інформація про канал** → клік по колу → **Завантажити фото**.

## 3.1. Публікація через Bot API (автоматично)

Після створення каналу я можу публікувати пости сам — через офіційний Telegram Bot API. Для цього потрібен бот і його токен.

### Один раз налаштувати

1. Відкрийте **@BotFather** → `/newbot` → дайте боту назву й username.
2. Скопіюйте токен виду `123456789:AA...`.
3. Додайте бота **адміністратором каналу** з правами:
   - **Post messages**
   - **Edit messages**
   - **Change channel info**
4. Створіть файл `.env` поруч зі скриптом (не надсилайте токен у чат):
   ```
   TELEGRAM_BOT_TOKEN=123456789:AA...
   TELEGRAM_CHANNEL=@rim_dlia_svoih
   ```
   Потім: `chmod 600 .env`
5. Перевірте: `python3 publish.py check`

### Команди

| Команда | Що робить |
|---|---|
| `python3 publish.py check` | перевіряє бота, канал, права й опис |
| `python3 publish.py setup` | ставить опис і аватар |
| `python3 publish.py pinned` | публікує й закріплює пост-знайомство |
| `python3 publish.py post 3` | публікує пост №3 з обкладинкою |
| `python3 publish.py all` | публікує всі 7 постів |
| `python3 publish.py pin 123` | закріплює повідомлення з `message_id=123` |

Додайте `--dry-run`, щоб побачити план без публікації.

### Обмеження Bot API

- Бот **не може створити канал** і **не може задати публічний юзернейм** — це робите ви.
- Бот **не вміє відкладати пости** (немає параметра `schedule_date`). Варіанти: публікую на вашу команду або запускаємо локальний планувальник (`cron`/`launchd`).
- Бот може писати лише в канал, де він адміністратор.
- Токен дає доступ лише до бота, не до вашого акаунта. Якщо токен витік — `/revoke` у @BotFather.

| `python3 automation/report.py` | перегляди, реакції, пересилання → `automation/report.json` |
| `python3 automation/report.py --json` | те саме у JSON |

| `python3 publish.py text content/promo-ukrtelegram.txt` | публікує текст із файлу |
| `python3 publish.py file content/extra/<slug>.md` | публікує пост з обкладинкою `covers/<slug>.png` |

**Сайт:** https://ucrainiroma.it/ · репозиторій `terkin/rim-dlia-svoih` · GitHub Pages з папки `/docs`.

### Окремі пости поза тижневим планом

1. Текст → `content/extra/YYYY-MM-DD-slug.md` (один пост, без код-блоків, підтримує `**жирний**`).
2. Обкладинка → додати запис у `covers/generate.py`, згенерувати `python3 covers/generate.py` і конвертувати:
   `rsvg-convert -w 1080 -h 810 covers/YYYY-MM-DD-slug.svg -o covers/YYYY-MM-DD-slug.png`.
3. Публікація → `python3 publish.py file content/extra/YYYY-MM-DD-slug.md`.
4. Сайт → `python3 automation/site.py` → commit → push → `python3 automation/indexnow.py`.

### Італійська версія (`/it/`)

Сайт двомовний: українська — у корені, італійська — у `/it/`. Сторінки пов'язані `hreflang`
(`uk`, `it`, `x-default` → українська), у шапці є перемикач мови.

Щоб додати переклад, достатньо покласти файл із тим самим slug:

```
content/it/YYYY-MM-DD-slug.md     →  /it/posts/YYYY-MM-DD-slug.html
```

- обкладинка спільна — `covers/<slug>.png`;
- якщо перекладу немає, італійська сторінка не створюється, а на українській не буде `hreflang="it"`;
- італійська головна показує лише перекладені пости й веде на українську решту;
- переклад без відповідного поста зупиняє генерацію з помилкою (захист від друкарських помилок у slug).

Правило: перекладаємо не все підряд, а насамперед evergreen-матеріали (codice fiscale, оренда, школа, лікар) —
саме їх шукають італійською. Новинні пости тижня можна залишати лише українською.

### Довгі матеріали (довші за 1024 символи)

Підпис у Telegram обмежений 1024 символами, а сторінка на сайті — ні. Тому для гідів робимо два файли:

1. `content/extra/<slug>.md` — повний текст, іде на сайт (`/posts/<slug>.html`);
2. `content/channel/<slug>-post.md` — коротка версія для каналу;
3. публікація: `python3 publish.py file content/channel/<slug>-post.md --cover covers/<slug>.png`.

Обкладинка спільна, тому в пості каналу обов'язково посилання на повну версію на сайті.

Повна архітектура AI-автопілота — у `ai-promotion.md`. Наступні модулі: `draft.py` (LLM-редактор) і `approve.py` (бот погодження). Для `draft.py` потрібен ключ LLM API у `.env`.

## 6. Як публікувати

- **Автоматично:** `python3 publish.py post 3` або `python3 publish.py all` (див. розділ 3.1).
- **Відкладені пости:** у Telegram Desktop — права кнопка на «Надіслати» → **Запланувати**. На телефоні — утримуйте кнопку надсилання.
- **Форматування:** виділіть текст → **B** (жирний), або `Ctrl/Cmd + B`. Посилання — через **Створити посилання**.
- **Альбом:** виберіть 2–10 фото → один спільний підпис (до 1024 символів).
- **Текст без фото:** до 4096 символів — зручно для великих дайджестів.

## 8. Правила й юридичне

- **Не офіційна установа.** Додайте у закріплений пост: «Ми не офіційна організація, просто сусіди, які вже трохи орієнтуються».
- **Джерела.** Завжди вказуйте видання й дату — це захищає від звинувачень у фейках.
- **Фото.** Не беріть чужі фото без дозволу; для анонсів краще свої кадри, офіційні прес-фото або власні ілюстрації.
- **Медичні/юридичні поради.** Пишіть «це не консультація», давайте контакти установ.
- **Модерація.** Заборона образ, політичних сварок, реклами без домовленості.
