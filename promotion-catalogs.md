## 4. Telegram SEO — як вас знаходять у самому Telegram

Пошук Telegram ранжує насамперед **видиму назву**, потім **username**. Опис і закріплений пост — допоміжні.

### 4.1. Назва каналу

Було: `Рим для своїх`. **Змінено на:** `Рим для своїх | Українці в Римі` ✅

- бренд «Рим для своїх» залишається першим;
- додано ключі «Українці» і «Рим»;
- username **не змінювався** — `@rim_dlia_svoih`;
- змінено через Bot API (`setChatTitle`), це зворотна дія.

### 4.2. Опис

Уже містить «українців у Римі», «події», «транспорт», «житло», «робота», «здоров'я», «безпека». Це добре — не чіпати.

### 4.3. Закріплений пост

Має містити ті самі ключові слова, що й назва: `Рим`, `українці`, `Італія`, `робота`, `житло`, `транспорт`. Зараз пост це покриває.

### 4.4. Хештеги

Використовуйте стабільний набір — він працює як внутрішня навігація і як сигнал теми:

`#Рим` `#УкраїнціВРимі` `#Італія` `#транспорт` `#події` `#діти` `#робота` `#житло` `#довідка`

### 4.5. Публічна вебверсія

`https://t.me/s/rim_dlia_svoih` — це індексована сторінка. Вона вже віддає пости без JS. Саме її читають пошукові роботи й каталоги.

### 4.6. Внутрішні перелінковки

У кожному пості давайте 1–2 посилання на попередні пости каналу (`https://t.me/rim_dlia_svoih/8`). Це збільшує глибину перегляду і допомагає пошуку.

### 4.7. Крос-пост у соцмережі (Bluesky / Mastodon)

Кожен пост сайту дублюється в соцмережі автоматично — `automation/crosspost.py`:

1. читає найсвіжіший запис із `docs/rss.xml` (заплановані на майбутнє пости пропускає);
2. публікує заголовок + короткий опис + посилання на сайт + хештеги;
3. зберігає опублікований link у `automation/.crosspost-state.json` — дублікатів не буде;
4. мережа пропускається, якщо в `.env` немає її ключів.

Щоб увімкнути (по 5 хвилин на акаунт, обидві мережі безкоштовні):

```
# Bluesky: bsky.app → Settings → App passwords
BSKY_HANDLE=ваше-ім’я.bsky.social
BSKY_APP_PASSWORD=xxxx-xxxx-xxxx-xxxx

# Mastodon: mastodon.social (або будь-який інстанс) → Preferences → Development → New app
MASTODON_BASE=https://mastodon.social
MASTODON_TOKEN=...
```

Перевірка: `python3 automation/crosspost.py --dry-run`.

Ті самі ключі можна додати як GitHub Secrets і викликати скрипт із Actions після кожного push.

## 5. Google SEO — щоб знаходили поза Telegram

Telegram-канал сам по собі індексується погано. Найнадійніший безкоштовний спосіб — **статична сторінка на GitHub Pages**, яка веде на канал.

### 5.1. Що має бути на сайті

- Одна головна сторінка українською: заголовок `Рим для своїх — телеграм-канал для українців у Римі`.
- Короткий опис, 5–7 блоків тем, кнопка `Відкрити в Telegram`.
- Останні 10–20 постів (генеруються з `content/`).
- `sitemap.xml`, `robots.txt`, `rss.xml`.
- Schema.org: `Organization` + `WebSite` + `ItemList` постів.
- `hreflang="uk"` + `hreflang="it"` + `x-default` (двомовна версія, див. 5.5).
- Open Graph / Twitter Card із обкладинкою (своя для кожного поста).

### 5.2. Домен

Сайт працює на власному домені: **https://ucrainiroma.it/** ✅

- домен: `ucrainiroma.it` (register.it, до 09.11.2027)
- DNS: A/AAAA → GitHub Pages, HTTPS-сертифікат видано, `https://` віддає 200
- репозиторій: `https://github.com/terkin/rim-dlia-svoih` (публічний)
- GitHub Pages: гілка `main`, папка `/docs`, `docs/CNAME` = `ucrainiroma.it`
- генератор: `python3 automation/site.py`

### 5.3. Індексація

1. ✅ **IndexNow** — 15 URL (укр. + іт. версії) надіслано на `ucrainiroma.it` (`HTTP 200`), файл ключа на сайті.
2. ⏳ **Google Search Console** — додати сайт вручну, надіслати `sitemap.xml` (потрібен Google-акаунт).
3. ⏳ **Bing Webmaster Tools** — додати сайт вручну (IndexNow уже працює, але панель дає статистику).
4. Перевірити через 3–7 днів: `site:ucrainiroma.it`.

Lighthouse на живому сайті: **Accessibility 100 · Best Practices 100 · SEO 100**.

### 5.4. Backlinks

Кожен каталог із розділу 1–2 — це безкоштовне посилання на сайт/канал. Після лістингу перевірте, чи є на ньому `https://t.me/rim_dlia_svoih`.

### 5.5. Італійська версія `/it/`

Двомовна структура: українська в корені, італійська в `/it/`, сторінки зв'язані `hreflang`
(`uk` / `it` / `x-default` → українська), у шапці — перемикач мови, `sitemap.xml` містить обидві версії з `<xhtml:link>`.

- переклад: `content/it/<slug>.md` (той самий slug, що й обкладинка) → `/it/posts/<slug>.html`;
- італійська головна: `https://ucrainiroma.it/it/`;
- перекладаємо насамперед evergreen-запити: «codice fiscale», «affitto Roma», «medico di base», «scuola per ucraini Roma»;
- новинні пости тижня можна не перекладати — вони швидко втрачають актуальність.

Навіщо: українці в Римі часто гуглять італійською, бо вся офіційна термінологія італійська. Це той самий пошуковий попит, але ширший.
